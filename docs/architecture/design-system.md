## Typography

Font stack: `ui-sans-serif, system-ui, sans-serif` (system fonts)

- Headings: 600 weight
- Body: 400 weight, 16px base size, 1.5 line-height

## Spacing

Base unit: 4px (use multiples: 4, 8, 16, 24, 32)

## Radius

- `--radius-control`: 0.625rem (10px) — inputs, buttons
- `--radius-card`: 0.875rem (14px) — cards, dialogs

## Shadows

- `--shadow-card`: layered card shadow
